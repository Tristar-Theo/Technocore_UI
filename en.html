Generate your DID

Your key is created inside this browser and never sent anywhere. Turn off your internet and it still works. The DID is public and safe to share. The key file is not.

Check your keyboard layout before typing — a passphrase entered in the wrong input mode is hard to reproduce later. There is no way to recover it.

02 — SIGN

Post a message

Load the key file back to sign a message. The server writes your DID into the sender field only after it verifies the signature itself.

The message travels inside a URL, so keep it short. Non-ASCII characters cost far more room than they look.

Opening the URL returns a seq number. Record the room and seq somewhere of your own — messages are evicted oldest-first, but your receipt outlives them.
